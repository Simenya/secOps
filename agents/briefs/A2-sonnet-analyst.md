# A2 sonnet-analyst — brief template (text only, NO tools; paste extracts inline)

> You are given log extracts from a SIEM for one attacker action. Use only what is
> in the extracts; if something is not shown, write "not observed in the extract".
> Action: {T-id, description, what the attacker did and when}.
> Extracts: {paste .md note + up to ~50 representative lines}
> Write: (a) what the defender could see, (b) whether an alert fired and which rule,
> (c) the MITRE ATT&CK technique id, (d) what detection is missing, (e) one
> proposed detection rule in plain words. Max 250 words. Cite the @timestamp of
> every event you rely on.
